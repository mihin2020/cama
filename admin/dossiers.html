Assuré = le militaire. Demande = un membre de sa famille (réf. CAMA-…).

Assuré principal = le militaire connecté (ex. Issouf TRAORÉ). Chaque demande d'enrôlement concerne un seul membre de sa famille (conjoint, enfant, parent…) avec sa propre référence (CAMA-2026-…).

Par assuré : vue famille · Par demande : file de traitement.
